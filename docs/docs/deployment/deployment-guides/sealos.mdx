# Deploying Hasura GraphQL Engine on Sealos

## Introduction

This guide shows how to deploy Hasura GraphQL Engine v2 on [Sealos](https://sealos.io) with a community-maintained
template. The template includes Hasura GraphQL Engine, the Hasura Data Connector Agent, and a managed PostgreSQL
database.

:::info Community-maintained template

The deployment template is maintained in the
[Sealos application templates repository](https://github.com/labring-actions/templates/tree/kb-0.9/template/hasura).

:::

## Prerequisites

- A [Sealos account](https://sealos.io)
- An admin secret for your Hasura instance

## One-click deploy on Sealos

Click the button below to open the Hasura template in the Sealos App Store:

[<img src="https://sealos.io/Deploy-on-Sealos.svg" className="no-shadow" width="200" alt="Deploy on Sealos" />](https://sealos.io/products/app-store/hasura)

1. Enter the `admin_secret` for your Hasura instance.
2. Click **Deploy** and wait for every component to become ready.
3. Open the public URL generated for Hasura.
4. Enter the same admin secret to access the Hasura Console.

The managed PostgreSQL database is registered in Hasura as the default data source during deployment.

## Persistence and secrets

Sealos provides persistent storage for PostgreSQL. The template reads database credentials from the Kubernetes Secret
generated by the managed PostgreSQL service and passes the admin secret from the deployment form to Hasura.

The template creates a single-replica starter deployment. Review replica counts, backup retention, resource limits, and
network policies for your production requirements.
