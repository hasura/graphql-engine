# Export the Hasura GraphQL Schema

## Introduction

If you need to share, introspect or export the GraphQL schema, you can use community tooling such as
[graphqurl](https://github.com/hasura/graphqurl), [Apollo CLI](https://github.com/apollographql/apollo-tooling),
[get-graphql-schema](https://github.com/prismagraphql/get-graphql-schema), etc.

## Which schema gets exported

Hasura generates a separate GraphQL schema for each role, so the exported schema depends on the role the introspection
request is made with:

- **With the admin secret** (`X-Hasura-Admin-Secret`), the request is made as the `admin` role and you get the full
  schema, including every query, mutation and subscription root field.
- **Without the admin secret**, if the GraphQL Engine is running with an admin secret, the request is rejected unless an
  [unauthorized role](/auth/authentication/unauthenticated-access.mdx) is configured. If one is configured, you get the
  schema of that role, which only contains what its permissions allow. For example, if the role has no insert, update or
  delete permissions, the schema has no mutation root (`mutationType` is `null`).
- **With the admin secret and an `X-Hasura-Role` header**, you get the schema of that role. This is useful to see the
  API exactly as a given role sees it.

If [introspection is disabled](/security/disable-graphql-introspection.mdx) for a role, its schema cannot be exported.

## Using **graphqurl**

For example, using `graphqurl`, you can get the schema as follows:

Run `npm install -g graphqurl` to install `graphqurl`. Then you can run the following commands to download the GraphQL
schema:

```bash
# If the GraphQL Engine is running at https://my-graphql-engine.com/v1/graphql,
# without an admin secret
gq https://my-graphql-engine.com/v1/graphql --introspect > schema.graphql

# If Hasura GraphQL Engine is running with an admin secret
gq https://my-graphql-engine.com/v1/graphql -H 'X-Hasura-Admin-Secret: adminsecretkey' --introspect > schema.graphql
```

By default, it downloads the schema in `.graphql` format. If you want it in JSON format, you can use an additional flag
`--format json`:

```bash
# Getting the schema in .json format
gq https://my-graphql-engine.com/v1/graphql --introspect --format json > schema.json
```

## Using **Apollo CLI**

Using Apollo CLI, you can get the schema as follows:

Run `npm install -g apollo` to install the Apollo CLI. You can then run the following command to download the GraphQL
schema:

```bash
# If the GraphQL Engine is running at https://my-graphql-engine.com/v1/graphql,
# without an admin secret
apollo schema:download --endpoint https://my-graphql-engine.com/v1/graphql

# If Hasura GraphQL Engine is running with an admin secret
apollo schema:download --endpoint https://my-graphql-engine.com/v1/graphql --header 'X-Hasura-Admin-Secret: adminsecretkey'
```

Note that `apollo schema:download` is an alias of the command
[apollo service:download](https://github.com/apollographql/apollo-tooling#apollo-servicedownload-output).

By default, this downloads the schema to a file called `schema.json`. This command has no other output types.
